# language-agnostic-core

## Purpose

Baseline coding guidance that applies across languages and stacks.

## When to use

- You want consistent engineering behavior in any repository.
- You need a foundation before adding language/framework-specific packs.

## What it provides

- `.github/instructions/language-agnostic-core.instructions.md`

## Best paired with

- Any language/framework pack in this repository.

## Not intended for

- Language-specific implementation details.

## Manual integration

Copy this pack's `.github` content into your target repository.
