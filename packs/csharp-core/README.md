# csharp-core

## Purpose

Core C# and .NET coding guidance for production codebases.

## When to use

- Your repository contains C#/.NET source code.
- You want consistent C# architecture and implementation patterns.

## What it provides

- `.github/instructions/csharp.instructions.md`

## Best paired with

- `aspnetcore-api`
- `postgres-efcore`
- `dotnet-unit-tests`

## Not intended for

- API contract conventions (use `aspnetcore-api`).
- EF/Postgres persistence specifics (use `postgres-efcore`).

## Manual integration

Copy this pack's `.github` content into your target repository.
