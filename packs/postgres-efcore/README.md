# postgres-efcore

## Purpose

Guidance for PostgreSQL and EF Core modeling, querying, and migration workflows.

## When to use

- Your repository uses EF Core with PostgreSQL.
- You want consistent data access and migration practices.

## What it provides

- `.github/instructions/postgres-efcore.instructions.md`

## Best paired with

- `csharp-core`
- `aspnetcore-api`

## Not intended for

- General C# architectural guidance outside persistence concerns.

## Manual integration

Copy this pack's `.github` content into your target repository.
