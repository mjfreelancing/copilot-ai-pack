# dotnet-unit-tests

## Purpose

Deterministic .NET unit testing guidance for isolated and maintainable tests.

## When to use

- You want repeatable unit test structure and conventions in .NET projects.
- You need clear boundaries between unit and integration tests.

## What it provides

- `.github/instructions/dotnet.tests.instructions.md`

## Best paired with

- `csharp-core`
- `aspnetcore-api`
- `aspnetcore-integration-tests`

## Not intended for

- Hosted API integration test strategy (use `aspnetcore-integration-tests`).

## Manual integration

Copy this pack's `.github` content into your target repository.
