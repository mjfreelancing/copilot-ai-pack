# react-client

## Purpose

React client-side guidance for component architecture, state, and UI behavior.

## When to use

- Your repository includes a React frontend.
- You want framework-level UI conventions and patterns.

## What it provides

- `.github/instructions/react-client.instructions.md`

## Best paired with

- `typescript-core`
- `prompts-testing`

## Not intended for

- Language-level TypeScript guardrails (use `typescript-core`).
- Backend/API architecture guidance.

## Manual integration

Copy this pack's `.github` content into your target repository.
