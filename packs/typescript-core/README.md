# typescript-core

## Purpose

Core TypeScript guidance for reliable typing, runtime behavior, and maintainability.

## When to use

- Your repository contains TypeScript or JavaScript code.
- You want strong language-level guardrails.

## What it provides

- `.github/instructions/typescript.instructions.md`

## Best paired with

- `react-client`
- `prompts-testing`

## Not intended for

- React architecture and UI behavior (use `react-client`).

## Manual integration

Copy this pack's `.github` content into your target repository.
